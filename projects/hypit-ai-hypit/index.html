常见问题

hypit-ai/hypit 是什么？

为支持 Skills 的 AI 编程 Agent 提供可编辑、可重跑的视频制作工作流，适合希望复用和迭代视频流程的内容团队与开发者。

Hypit 的许可证和费用是什么？

仓库采用 Hypit Open Source License（基于 Apache 2.0 的附加条件版本，非标准 Apache 2.0）。框架本身不收席位或渲染费；Agent、模型与云资源可能另计。请在商用集成前阅读当前许可证。

试用时要注意什么？

先用非关键素材小样试跑，并确认参考视频、肖像、声音、音乐等素材的使用权。快速迭代中的项目仍需自行验证是否满足制作要求。
